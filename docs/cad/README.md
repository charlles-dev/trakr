# Trakr CAD - Guia de Impressão

## Parâmetros recomendados
- Material: **PETG**
- Infill: modelo **Gyroid**, ~30%
- Camada: 0,2 mm
- Suportes: mandíbulas para os encaixes das ferramentas

## Workflow
1. Edite o design paramétrico em `cad/scripts/SmartToolboxUI.py` (Fusion 360).
2. Exporte as peças para `cad/exports/` (.STL/.3MF).
3. Fatie usando os parâmetros acima.
4. Imprima e monte o insert da maleta.

## BOM de impressão
- Filamento PETG: ~450 g por maleta completa.
