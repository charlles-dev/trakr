💡 Catálogo de Melhorias — Hardware & Software
=============================================

Documento **vivo** para discutir ideias **novas** de melhoria do ecossistema
Trakr (TRK-Finder). Cada item tem um **ID único** para
referenciarmos na conversa (ex.: "vamos fazer o `NOV-01`?").

> ⚠️ **Importante:** o primeiro lote de melhorias (EN-01..06, RF-01..05,
> LOC-01..06, SEC-01..06, SEN-01..06, HMI-01..06, APP-01..05 e MFG-01..06) foi
> **aprovado e movido** para a seção "Add-ons e Plugins" do
> [`roadmap.md`](./roadmap.md). Este catálogo agora só recebe **ideias novas**,
> ainda em discussão.

Convenções
----------

| Campo   | Valores                                              |
| ------- | ---------------------------------------------------- |
| Tipo    | `HW` (eletrônico/mecânico) · `SW` (firmware/app)    |
| Produto | `TRK-Finder` (rastreador) · `App` · `Firmware` |
| Esforço | `B` baixo · `M` médio · `A` alto                    |
| Impacto | `B` baixo · `M` médio · `A` alto                    |
| Status  | 💬 discutindo · 🔧 planejado · ✅ adotado · ❌ descartado |

Dependências são anotadas no item (ex.: "depende do `SEN-03`"). Quando uma
ideia for aprovada, ela **migra** para a seção de Add-ons do roadmap e sai
daqui.

Como discutir
-------------

1. Cada item novo recebe um ID sequencial da categoria (`EN-07`, `RF-06`, ...).
2. Mude o `Status` de 💬 → 🔧 quando decidirmos executar, ✅ quando entregue.
3. Ao aprovar, o item migra para `docs/roadmap.md` (Add-ons) e sai daqui.
4. Novas ideias entram na categoria certa, com esforço/impacto estimados.
